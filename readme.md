# 🛡️ Production Image Forensics & Attendance OCR API

A high-performance FastAPI backend designed for an attendance tracking system. It acts as a multi-layered security gatekeeper, validating the authenticity of user selfies by checking watermarks, extracting GPS data via Vision LLMs, scanning for editing software metadata, and detecting AI-generated images.

## 🏗️ System Architecture & Flow

The system uses a **Gatekeeper Architecture** to save cost and processing time. It runs the cheapest, fastest validation first. If the image fails the OCR check, it short-circuits the process, avoiding expensive API calls entirely.

```mermaid
graph TD
    A["Client sends Image: Base64, URL, or Path"] --> B["API: /validate-images"]
    
    B --> C{"Is Image Valid?"}
    C -- No --> D["Return Error: File not found"]
    C -- Yes --> E["Layer 1: OCR Extraction (Gemini)"]
    
    E --> F{"Watermark & Timestamp Valid?"}
    
    F -- No --> G["Gatekeeper Triggered: INVALID IMAGE"]
    G --> H["Skip AI & Forensics (Save Costs)"]
    H --> Z["Return Response to Client"]
    
    F -- Yes --> I["Layer 2: Metadata Forensics"]
    I --> J{"Is Edited / Forged?"}
    
    J -- Yes --> K["Flag: Edited Image"]
    K --> Z
    J -- No --> L["Layer 3: AI Detection (Sightengine)"]
    
    L --> M{"AI Score >= 0.40?"}
    M -- Yes --> N["Flag: AI Generated"]
    M -- No --> O["Flag: Original / Authentic"]
    
    N --> Z
    O --> Z
```

---

## 🛡️ The 3 Layers Explained

- **Layer 1: OCR Gatekeeper (Gemini Vision):** Extracts GPS, Timestamp, and Watermark. It cross-validates that the timestamp on the GPS box matches the watermark, and checks if the watermark has overlapping/scrambled characters. If this fails, the image is instantly rejected.
- **Layer 2: Metadata Forensics:** Reads EXIF/XMP data to detect if the image was opened/saved by editing software (Photoshop, Lightroom, Canva, etc.).
- **Layer 3: AI Generation Detection (Sightengine):** Scans the pixels to determine if the image was synthetically generated by Midjourney, DALL-E, or Stable Diffusion. (Only runs if Layer 2 passes).

- **Framework:** FastAPI (Python 3.13)
- **AI/Vision:** Google Gemini API (`google-genai`)
- **AI Detection:** Sightengine API
- **Image Processing:** Pillow (PIL)

## 🔐 Environment Variables

Create a `.env` file in the `app/` directory. You must obtain keys for both Sightengine and Google Gemini.

```env

SIGHTENGINE_API_USER_1=your_user_here
SIGHTENGINE_API_SECRET_1=your_secret_here
SIGHTENGINE_API_USER_2=your_fallback_user_here
SIGHTENGINE_API_SECRET_2=your_fallback_secret_here

# Google Gemini API (Free Tier: 1500 req/day)
GEMINI_API_KEY=AIzaSyYourGeminiKeyHere
```

## ⚙️ Local Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jamaludeen001/AIImageDetection.git
   cd AIImageDetection/Project-1-AI-Image-detection
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # Mac/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up `.env`:** Add your API keys to `app/.env` as shown above.

## 🚀 Running the Application

1. **Start the FastAPI server locally:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

2. **Web UI:** Open `http://127.0.0.1:8000/` in your browser.
3. **API Docs (Swagger):** Open `http://127.0.0.1:8000/docs`.

```json

        "data:image/jpeg;base64,/9j/4AAQSkZJRg...",
        "https://example.com/attendance_selfie.jpg"

}
```

## ☁️ Deployment (Render)

This repository is pre-configured for Render.com using the `Starter` ($7/mo) or `Standard` ($25/mo) instance.

1. Push your code to GitHub (Ensure `.env` is in `.gitignore`).
2. In Render, create a **New Web Service**.
3. Connect your GitHub repository.
4. Set the **Root Directory** to `Project-1-AI-Image-detection` (if nested).
5. Set the **Build Command**: `pip install -r requirements.txt`
6. Set the **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
7. **Add Environment Variables:** Add `GEMINI_API_KEY`, `SIGHTENGINE_API_USER_1`, etc., in the Render Dashboard.
8. Deploy!
